# 개인정보 수집 및 이용 동의서(필수)

link-like-tracker(이하 llt)는 Google 계정으로 로그인한 사용자의 시청 기록을 여러 기기에서 이어볼 수 있도록 필요한 개인정보를 아래와 같이 수집하고 이용합니다.

## 1. 수집하는 개인정보

- Google 계정 기본 정보: 이메일 주소, 이름, 프로필 이미지 URL, Google 계정 식별자
- 서비스 계정 정보: Supabase 사용자 ID
- 기기 정보: 브라우저에서 생성한 기기 식별자, 기기 이름, 최근 동기화 시각
- 시청 기록: 영상 ID, 시청 여부, 카테고리 수정값, 기록 수정 시각
- 설정 정보: 진행률 표시 기준, 비공개 영상 숨김 여부
- 요청 기능 사용 시 입력한 정보: 추가 요청 링크, 영상 제목, 분류, 기수, 요청 내용
- 서비스 이용 과정에서 자동으로 생성되는 정보: 접속 로그, IP 주소, 브라우저 및 기기 정보, 페이지 방문 정보

Google 계정 비밀번호는 llt에 제공되지 않으며, llt는 Google 계정 비밀번호를 저장하지 않습니다.

## 2. 이용 목적

- Google 계정 로그인 및 사용자 식별
- 스마트폰, 태블릿, 웹 사이의 시청 기록 동기화
- 기기별 기록 확인, 기록 합치기, 충돌 해결
- 사용자가 선택한 보기 설정 저장 및 동기화
- 콘텐츠 추가 및 수정 요청 접수
- 서비스 안정성 확인, 오류 분석, 부정 이용 방지

## 3. 보유 및 이용 기간

- 계정 정보, 시청 기록, 동기화 설정은 사용자가 삭제를 요청할 때까지 보관합니다.
- 콘텐츠 추가 및 수정 요청은 처리 완료 후 운영 기록 관리를 위해 최대 1년간 보관할 수 있습니다.
- 접속 로그 및 분석 정보는 서비스 안정성 확인과 보안 목적에 필요한 기간 동안 보관합니다.
- 법령에 따라 보관이 필요한 정보는 해당 법령에서 정한 기간 동안 보관합니다.
- 브라우저에 저장되는 로컬 데이터는 사용자가 브라우저 저장소를 삭제하거나 앱에서 기록을 초기화할 때까지 기기에 남을 수 있습니다.

## 4. 동의 거부 시 불이익

사용자는 개인정보 수집 및 이용에 동의하지 않을 수 있습니다. 다만 동의하지 않으면 Google 로그인, 시청 기록 동기화, 기기별 기록 관리 기능을 사용할 수 없습니다.
